# Kế hoạch ngân sách dự án quán bánh mì buổi sáng

## Mục tiêu
Tạo một bản trình bày PowerPoint chuyên nghiệp bằng tiếng Việt, theo phong cách sạch, hiện đại, phù hợp cho bài tập hoặc báo cáo dự án.

## Cách tạo file PPTX
1. Cài đặt dependency:
   ```bash
   pip install python-pptx
   ```
2. Chạy script:
   ```bash
   python generate_ppt.py
   ```
3. File đầu ra:
   - `Ke_hoach_ngan_sach_quan_banh_mi_buoi_sang.pptx`

## Cấu trúc slide đề xuất
1. Cover / tiêu đề
2. Mô tả dự án
3. Mục tiêu ngân sách
4. Doanh thu dự kiến
5. Chi phí dự kiến
6. Bảng tổng hợp ngân sách
7. Lợi nhuận dự kiến
8. Nguồn tài trợ
9. Thời gian thực hiện
10. Quy trình đánh giá kết quả
11. Điểm hòa vốn
12. Phương án cắt giảm 15%
13. Cắt giảm theo khoản mục
14. Kế hoạch dự phòng
15. Kiểm soát ngân sách
16. Kết luận

## Ghi chú
- Slide được xây dựng dựa trên nội dung đã cung cấp.
- Nếu cần, có thể bổ sung hình ảnh, logo, sơ đồ, biểu đồ hoặc chỉnh màu sắc theo yêu cầu.
